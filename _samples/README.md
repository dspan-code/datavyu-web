# 线上样本工程（`.opf`）

这个目录里的 `.opf` 会出现在网页版的「文件 → 从本仓库打开…」里，
别人打开网址就能直接载入，不用先拿到文件。

## 怎么加你自己的

1. 把你的 `.opf` 复制进本目录（**文件名用英文/数字**，避免网址转义问题）
2. 编辑 `samples.json`，在 `samples` 数组里加一行：

```json
{ "file": "my-project.opf", "title": "我的工程", "desc": "一句话说明" }
```

3. 提交并推送，等 GitHub Pages 重新部署（约 30 秒）

## ⚠️ 注意

放进这个目录的 `.opf` **是公开的**（和仓库一起公开）。
研究数据、被试信息、可识别身份的视频内容，**不要**放这里。
要分享给特定的人，用「文件 → 导出 .opf」私发文件本身。
